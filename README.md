# Brick — Time Block Builder

**Brick** is a sleek, minimalist time-blocking task management app designed to help you organize your workflow into estimated time slots ("bricks").

## Features

- **Time-Block Task Creation:** Create tasks with flexible duration inputs (e.g., `45min`, `1.5 hr`).
- **Total Duration Tracking:** Instantly visualizes total task counts and cumulative estimated time across all bricks.
- **Task Source Tagging:** Distinguish between tasks created manually (`Self`) vs. generated automatically (`AI`).
- **Dark Mode UI:** Designed with a high-contrast dark theme optimized for daily focus.

## Tech Stack

- **Frontend:** React / Vite (HTML5, CSS, Modern JavaScript/TypeScript)
- **Styling:** CSS / Modern UI frameworks
